# E-Commerce Data Analysis

## Project Overview
This project analyzes e-commerce customer orders, payment behavior, delivery performance, and customer reviews using Excel, SQL, Power BI, and Tableau.

## Tools Used
- Excel
- SQL
- Power BI
- Tableau

## KPIs
- Weekday Vs Weekend Payment Statistics (order_purchase_timestamp)
- Number of Orders with Review Score 5 and Payment Type as Credit Card
- Average Delivery Days for Pet Shop Orders
- Average Price and Payment Values of Customers from Sao Paulo City
- Relationship Between Shipping Days and Review Scores
- Total Orders
- Total Revenue
- Average Order Value
- Top Selling Product Categories

## Insights
- Analyzed customer purchasing behavior on weekdays and weekends
- Identified highly satisfied customers using review scores
- Evaluated delivery performance for pet shop category
- Compared customer payment and pricing trends in Sao Paulo
- Studied impact of shipping delays on customer review scores
- Identified top-performing product categories and revenue trends
